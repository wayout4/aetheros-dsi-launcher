# Expanded Nintendo DS/DSi Homebrew Game Catalog

**Purpose:** discover 80+ additional community-made DS game projects for your own SD card. This is a curated discovery list, not a ROM bundle. The project does not redistribute game binaries, and a catalog entry is not a claim that the latest release has been tested on your particular DSi.

## Download and compatibility rules

- Start at the [GameBrew DS homebrew games index](https://www.gamebrew.org/wiki/List_of_DS_homebrew_games) or the [Universal-DB DS catalog](https://db.universal-team.net/ds/category/game). Search the exact title there and follow the author's release/download link.
- Only download files the author or catalog makes available. Check the license, required data folders, save location, and DSi/DS compatibility notes for each release.
- Some entries are demos, old builds, fan projects, or may require data files. Availability does not guarantee a current download, a clean license, DSi-mode support, or that it boots.
- Do not download commercial game ROMs from unofficial ROM sites. For commercial games, use a dump you are legally entitled to use.
- Copy each downloaded `.nds` to your SD card and keep its companion data folder at the exact path stated by its author.
- NitroLauncher can currently browse and structurally validate files; **it does not launch selected games directly**. Start them through a compatible frontend such as TWiLight Menu++.

## Direct-launch integration gate

Do not treat an arbitrary `nds-bootstrap` binary as a drop-in chainloader. The supported handoff depends on the frontend, loader version, boot environment, launch arguments/configuration, and return behavior. Until that interface is integrated and tested, NitroLauncher must continue to tell the truth and let TWiLight Menu++ launch the selected file. The next implementation step is to pin a supported DS-Homebrew/TWiLight Menu++ release and integrate its documented launcher path with CI and emulator/hardware acceptance tests.
